# 新P4 — 提案コンセプト

### 📋 現状の文章（旧P4）

```
見えなかった強みを「見える化」し、選ばれる「問題解決力」を可視化する

仕様書には「将来的に最適なソリューション提供企業とのマッチング事業を展開」と明記されている。本業務はその前段。今年度のうちに、①誰が何をできるかの情報の基盤と、②取材を通じた事業者との関係性の基盤を築く。

だから納品後も、市役所への引き継ぎ・運用支援、事業者が自分で情報を更新できる仕組みづくりまで伴走する。
```
