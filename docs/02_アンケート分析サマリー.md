## 1. 業種・規模・地域構成（589事業所）

### 産業別内訳（重要）
| 業種 | 事業所数 | 構成比 |
|---|--:|--:|
| **流通・商業** | **190** | **32.3%** |
| サービス業 | 173 | 29.4% |
| 建設業 | 129 | 21.9% |
| 製造業 | 84 | 14.3% |
| 分類不可 | 13 | 2.2% |
| **計** | **589** | 100% |

→ **製造業は全体の14%にすぎない。流通商業・サービス業が60%超を占める。**
→ 既存企画書案・論点合意は **「製造業中心」のイメージで議論してきた**が、これは誤り。**業種バランスの母集団認識を修正する必要**。

### 規模別の傾向
- **個人企業・2名以下小規模が多い**：売上減少率も高い（個人企業76.5%減）
- 経営計画策定率は規模により大きく差：2人以下24.2% / 21人以上61.5%
- 「人手不足」感は全業種で増加（コロナ前39.6% → 現在46.5%）

## 2. 「強化したい点」と「強み」の構造（最重要）

事業所が今後何を強化したいか（事業所数）：

| 強化したい項目 | 該当数 | 「強み」と回答した数 | ギャップ |
|---|--:|--:|--:|
| **市場開拓・販路開拓** | **71** | 9 | **▲62** |
| **人材（採用・育成）** | **63** | 22 | ▲41 |
| **経営戦略・企画力** | **44** | 16 | ▲28 |
| 知名度・ブランド | 13 | 36 | +23 |
| 安定した資金繰り | 27 | 8 | ▲19 |

| 後継者の存在 | 21 | 15 | ▲6 |
| 教育・訓練 | 18 | 0 | ▲18 |
| 市場規模・販売効率 | 26 | 2 | ▲24 |

### ここから読み取れる重要な事実

1. **販路開拓が圧倒的トップ（71社）**：これは本業務（冊子・PV）が直撃するニーズそのもの
2. **人材（採用）が2位（63社）**：D軸（若年層・採用対象者）の正当性データが揃った
3. **強み「知名度・ブランド」36社 vs 強化したい「販路開拓」71社のギャップ**：
   - **「強みはあるが、市場で活かせていない」** という構造
   - → 既存企画書 p2「言語化の壁」の根拠データになる
4. **「経営戦略・企画力」44社が強化したい**：本業務のコンサル型取材（p6）の意義に直結

## 4. 販売先と販路の現実

### 得意先・販売先第1位の所在地（589社）

| 販売先 | 構成比 |
|---|--:|
| **田村市内** | **73.5%** |
| 郡山市 | 10.9% |
| 小野町・三春町・本宮市・二本松市 | 2.2% |
| 1〜3以外の県内市町 | 5.7% |
| **県外** | **7.7%** |
| 海外 | ほぼ0% |

→ **市内販売7割超。外から稼ぐ力が決定的に弱い。**
→ 売上「大幅増加」企業の60%が県外販売 → **外への販路を開拓した企業が成長している実証データ**
→ **「市外バイヤーへのアプローチ」が市内事業者の成長条件** = 本業務のA+B主軸（首都圏バイヤー・ソリューション企業）が正解だったことの裏付け

### 業種別2年後の見通しDI
- サービス業 +15.0（明）
- 建設業 +9.2
- 製造業 -34.0
- 流通商業 -40.6（暗）

→ **製造業・流通商業の見通しが特に厳しい** → 本業務の「販路拡大支援」がこの業種に最も貢献

## 6. 振興条例・支援施策の認知度（重要）

- 振興基本条例：**72.1%「知らない」**
- 市の支援施策：50%程度「知らない」
- 国・県の施策の方が認知度高い（20%以下「知らない」）

→ **市役所側の課題：自分たちの政策が事業者に届いていない**
→ 本業務の「冊子＋PV＋特設WEB＋AIコンシェルジュ」が **支援施策周知の機能も担う** という追加価値を訴求できる
→ **「その他20P」のエコノミックガーデニング事業紹介6P**（既存合意）がこの課題に直撃する設計だったことの裏付け

## 7. 5論点への影響（再検討）

### ✅ 論点1：想定ターゲット
**結論：方向性は正しい（裏付けデータあり）**
- A+B主軸（市外バイヤー・ソリューション企業）：市内販売73.5%・県外売上の高さ＝成長企業相関で裏付け
- D従軸（若年層・採用）：人材確保が課題2位（63社）、雇用支援要望31.6%で裏付け

### 🔄 論点2-2：情報源
**結論：方向性は正しい（裏付けデータあり）**
- A. 1,123事業所アンケート ← **これ自体（2022年実態把握調査）が市の最重要資料**
- C. 商工会会員リスト ← 立地メリット「商工会の支援」16.0%で裏付け
- D. Shift保有のふるさと納税事業者リスト ← 「地域資源を生かした産業づくり」21.7%で裏付け

### 🚨 論点2-3：特集5テーマ（**修正必要**）
**既存案は製造業寄り。データを反映して書き換えるべき。**

| # | 既存案 | 修正案（データ起点） | データ根拠 |
|--|---|---|---|
| 1 | 小ロット試作で動ける田村 | **「市場の外へ届ける」販路開拓編** | 強化したい1位71社、県外売上=成長相関 |
| 2 | 医療・エネルギー・ドローン新領域 | **「人を集める・育てる」採用・人材編** | 強化したい2位63社、雇用支援要望31.6% |

| 4 | OEM・受託製造のハブ田村 | **「市内のつながりで仕事をつくる」連携編** | 立地メリット「古くからのつながり」56.0% |
| 5 | 市内連携で生まれる新しいモノ | **「新しい挑戦に踏み出す」新事業・新領域編** | 強化したい3位「経営戦略・企画力」44社 |

### 🚨 論点2-5：業種・地域・規模バランス（**数値根拠あり**）
