# P2 — 事業理解と本業務の目的

**本業務は、冊子・PVの納品を目的とせず、田村市が令和7年度に着手した「生き残りをかけた中小企業成長戦略事業」の3カ年計画を離陸させる"起点"として位置づける。**

田村市は製造業が市内総生産の43.6%を占めるものづくりのまちであり、生産額は県内有数の伸びを示している（R6.3 地域経済調査）。一方で人口は2050年に半減見込み、20代の県外流出が突出している。豊かな技術がありながら、それを域外から「選ばれる新たな勝ち筋」に変える打ち手が、いま強く求められている。

これに対し田村市は、令和5年度の1,123事業所アンケートを起点に、製品発掘・新商品開発・販路拡大・ブランド化・雇用創出・経営者育成・起業支援・DX推進の8領域を「横断的・一貫した支援体系」へ束ね、行政主導から官民共創へ舵を切った。その推進母体が、経営者・経済団体・金融機関・学識者らで構成する **「エコノミックガーデニング田村」（本会議／実務者会合）** であり、両会議体の24提案の具現化が **「生き残りをかけた中小企業成長戦略事業」** である。

**本業務「田村の匠」冊子・PV製作は、この3カ年計画の1年目・最上流＝「田村の技術の見える化」を担う中核施策である。** 仕様書冒頭に「将来的に最適なソリューション提供企業とのマッチング事業を展開」と明記されているとおり、本業務は冊子・PVを納品して終わるものではなく、2年目のビジネスチャンス拡大事業、3年目の産業祭・ふるさと納税返礼品拡充・市内外マッチングへとつながる「滑走路」として設計する。

# P4 — 提案コンセプト

**見えなかった強みを「見える化」し、選ばれる「問題解決力」を可視化する**

### 「作って終わり」にしない

仕様書には「将来的に最適なソリューション提供企業とのマッチング事業を展開」と明記されている。本業務はその前段。今年度のうちに、①誰が何をできるかの情報の基盤と、②取材を通じた事業者との関係性の基盤を築く。冊子・PVは最終目的ではなく、来年度に本格マッチング事業を離陸させるための「**滑走路**」である。

### 「会社名」でなく「困りごと」から探せる

従来の企業カタログは「会社名→事業内容」で並ぶため、探す側が「どの会社に頼めるか」を事前に知っている必要があった。本業務では「**課題→解決できる企業**」へ並びの論理を反転させる（順引きから逆引きへ）。金属加工の専門用語がわからないバイヤーでも、「小ロットの試作を頼みたい」という自社の困りごとから田村の事業者にたどり着ける。冊子・WEB・AIすべてをこの"困りごと起点"で設計する。

### 事業者が主役、私たちは「黒子」

私たちの役割は、目立つ制作物をつくることではない。事業者が強みに気づく → 言語化される → 市内外から見つけられる → マッチングが生まれる → 田村の産業が育つ。この循環の「仕組み」を設計し、裏方として支えることにある。納品後も、市役所・商工会への引き継ぎ・運用支援、事業者が自分で情報を更新できる仕組みづくりまで伴走する。
