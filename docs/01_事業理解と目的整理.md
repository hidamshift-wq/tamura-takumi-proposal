# 田村の匠 PV制作プロポ — 事業理解と目的整理

> 作成：2026-05-28 / Claude（飛田さん向け分析メモ）
> 参照：実施要領・仕様書・別添資料「田村市生き残りをかけた中小企業成長戦略事業計画」
> 用途：企画書ドラフト前の前提固め。ここを共通理解にしてから個別ページに着手する。

## 1. 発注者（田村市）の置かれた状況

### 1-1. マクロな背景
- 田村市は福島県中通り東部の人口減少局面にある自治体。基幹産業は製造業（震災以前から産業集積あり）＋近年は医療機器、エネルギー、ドローン等の新産業も創出。
- 令和5年度に**市内1,123事業所を対象にアンケート調査**を実施 → 企業側のニーズが「製品発掘・新商品開発・販路拡大・ブランド化・雇用創出・経営者育成・起業支援・DX推進」と多岐にわたることが判明。
- 従来の「行政主導の単発施策」では対応しきれない、と市自身が認めている（仕様書2.目的「これまでの行政主導による施策の展開から一転し」）。

### 1-2. 構造的な舵切り
市は2つの会議体を新設し、政策形成プロセスそのものを変えた。

| 会議体 | 構成員 | 役割 |
|---|---|---|
| **エコノミックガーデニング田村本会議** | 経済団体長、中小企業同友会、学識者（大学教授）、金融機関（シンクタンク） | 提案の審査・検証 |
| **エコノミックガーデニング田村実務者会合** | 事業者（経営者）、経済団体（商工会経営指導員）、金融機関（支店長） | 調査・研究・施策提案 |

この2会議体から **これまでに24の事業提案** が出ており、本業務はその中から具現化された「生き残りをかけた中小企業成長戦略事業」群の一つ。

→ **本業務は「行政が決めた仕事を発注する」案件ではなく、「地域の経営者・経済団体・金融機関が議論して合意した方針」を市が代行発注している案件**。受託者は、市役所担当者の背後にいる事業者・経済団体・金融機関に対しても価値を示す必要がある。

## 2. 本業務の位置づけ（3カ年計画の中で）

別添資料p4「田村市生き残りをかけた中小企業成長戦略事業計画」より、本業務は **3カ年の事業計画の1年目・最上流に位置する**。

```
[1年目 R8年度] ← ★本業務はここ
  ・「田村の匠」製品紹介冊子・PVの製作 〜田村の技術の見える化〜
  ・中小企業交流セミナー（市内販路拡大）
  ・市内起業者・経営者ネットワーク構築事業（人材発掘・育成）
  ・地域通貨運用基礎調査
       ↓
[2年目 R9年度]
  ・ビジネスチャンス拡大事業（共同出展、商品開発助成、クロスオーバー助成金 1,000万円）
  ・地域企業イノベーション創出事業（事業構想チャレンジプログラム）
  ・デジタル地域通貨事業
       ↓
[3年目 R10年度]
  ・産業祭（市内外への発信、雇用機会提供）
  ・ビジネスチャンス拡大事業継続（クロスオーバー助成金 1,500万円）
```

並行して全期間：緊急新規雇用・離職者対策事業、地域EC基盤強化支援事業、生き残りをかけた中小企業成長戦略アドバイザリー事業 が走る。

最終的なゴール：**地域活性化＋ふるさと納税返礼品の拡充**（成長戦略事業計画p4 右側に明示）。

→ **本業務は「冊子とPVを作って終わり」ではない**。2年目以降のビジネスチャンス拡大事業、産業祭、デジタル地域通貨、EC事業すべての出発点となる **情報資産（田村の事業者の棚卸し）を作る業務**。これを外せば3年計画全体が立ち上がらない。

## 3. 本業務の真の目的（表層と深層）

### 3-1. 表層の目的（仕様書に書いてあること）
- 田村の事業者30社の製品紹介冊子（66P、1,000部）を作る
- 田村の事業者20社のPV（5-7分）を作る
- 令和9年3月19日までに納品する

### 3-2. 深層の目的（仕様書2.目的および実施要領1.目的から読み取れる本質）

> 「個別の得意領域において企業が共同で行う田村のものづくりを支援し、将来的に最適なソリューション提供企業とのマッチング事業を展開するとともに製品紹介やＰＶ製作によるトップセールスや異業種交流会、産業祭などでの販路拡大やマッチング機会の創出を図る」

これを分解すると、**冊子・PVは下記4つの「マッチング」を成立させるためのツール**である。

| マッチングの向き | 内容 | 評価事項 |
|---|---|---|
| **市内 × 市内** | 田村の事業者同士の補完関係（受発注・共同開発・技術補完・販路共有） | ④⑥ |
| **市内 × 市外（首都圏等）** | 田村の事業者と外部バイヤー／メーカーのマッチング、トップセールス | ① |
| **市内 × ソリューション提供企業** | 田村の事業者が抱える課題と、それを解く専門企業の引き合わせ | ① |
| **市内 × ふるさと納税ユーザー** | 田村の製品が返礼品ラインナップに加わる | ⑥ |

### 3-3. 「成果が達成された状態」の定義（仮説）

本業務が成功した1年後・3年後に、田村市がどんな状態になっていれば成功と言えるか：

**1年後（R9年3月：納品時）**
- 市長が他自治体・首都圏企業を訪問するときに冊子を手渡せる
- 商工課職員が展示会・交流セミナーで冊子・PVを使って事業者紹介ができる
- 田村の事業者自身が「自社が選ばれる理由」を言語化できている

**3年後（R10年度末：3カ年計画終了時）**
- 冊子・PVきっかけで生まれた市内企業間の共同受注／共同開発事例が複数生まれている
- 田村の事業者が新しい販路（市外・EC・ふるさと納税）を獲得している
- 「田村に相談すれば解決策が見つかる」という認知が業界内に生まれている
- 田村市の中小企業振興施策が他自治体のベンチマークになっている

## 4. 想定される活用シーン（冊子・PVの使われ方）

仕様書および別添資料から逆引きすると、納品物は以下のシーンで使われる前提で設計するべき。

| シーン | 担い手 | 使われ方 |
|---|---|---|
| 市長トップセールス | 田村市長 | 訪問先で冊子を手渡し |
| 展示会・商談会（共同出展） | 商工課＋掲載企業 | 冊子配布、ブースでPV上映、SNS短尺動画拡散 |
| 異業種交流会 | 商工課＋市内事業者 | 参加者間の「自社紹介」代わりに冊子を活用 |
| 産業祭（R10年度） | 市・市内事業者 | 来場者への配布、PVのモニター放映 |
| 求人・採用活動 | 掲載企業＋商工課 | 高校生・大学生向け企業紹介、若年層SNS訴求 |
| ふるさと納税返礼品開拓 | 商工課＋掲載企業 | 製品認知拡大、返礼品候補発掘 |
| WEB・SNS発信 | 受託者・市・各企業 | 24時間アクセス可能な情報源として |

→ **「読まれる」「見られる」だけでなく「使われる」設計が必要**。手渡される、検索される、引用される、共有される、そのすべてを想定する。

## 5. 評価事項の本質的な狙い（読み解き）

実施要領p4の評価事項①〜⑦は、表面的には7つの独立要件に見えるが、田村市側の本音を読むと以下のメッセージ。

| 評価事項 | 表向き | 本音（推察） |
|---|---|---|
| ① コンセプト＋マッチング期待 | コンセプトが明確であること | **冊子で終わらせるな。マッチング成立まで踏み込め。** |
| ② 事業所選定の基準・構成・プロセス | 構成・基準が明確であること | **30社／20社を恣意的に決めるな。再現性のあるロジックを示せ。1,123事業所のアンケート結果を活用しているか。** |
| ③ 技術PR＋効果的発信 | PR内容と発信方法 | **企業要覧の羅列にするな。「選ばれる理由」を引き出し、適切なチャネルで届けろ。** |
| ④ 既存事業との連携・マッチング機会 | 地域資源の連携 | **冊子・PV単体で完結させるな。2年目以降のビジネスチャンス拡大事業／中小企業交流セミナー／産業祭で「使える」設計にしろ。** |
| ⑤ ターゲット年齢層・職業・興味関心 | 想定ターゲット考慮 | **「誰に届ける」を定義してから作れ。バイヤー向け、若年層向け、ふるさと納税ユーザー向け、それぞれ違うはず。** |
| ⑥ ビジネスチャンス拡大／潜在発掘／ふるさと納税／エコノミックガーデニング促進 | 市の他事業への寄与 | **市の他施策との相乗効果を出せ。ふるさと納税・EC・産業祭との接続点を明示せよ。** |
| ⑦ 独自性・訴求力 | 独自性ある提案 | **仕様書通りなら誰でも作れる。Shiftだからできることを示せ。** |

配点70点が①〜⑦の「実施内容の企画提案」に集中していることの意味：
**「冊子とPVを作る能力」ではなく「マッチングを生むエコシステム設計能力」を問うている。**

## 6. 田村市側の暗黙の期待・懸念（推察）

### 6-1. 暗黙の期待
1. **3カ年計画の最上流を担う重みを理解した提案**：1年目で失敗すると2年目以降が立ち行かない
2. **エコノミックガーデニング会議体（事業者・経済団体・金融機関）への成果説明がしやすい構造**：市役所担当者が本会議で報告できる形
3. **継続性ある情報資産**：紙の冊子で完結せず、更新・拡張可能なデータ資産になっていること
4. **田村の事業者自身の意識変化**：取材プロセスを通じて事業者が自社価値を再認識する副次効果

### 6-2. 懸念事項（応札者に見せたくない不安）
1. 冊子・PVを作っても「実際にマッチングが起きるのか？」という効果検証への不安
2. 取材対象30社／20社の選定で **特定企業に偏ってはいけない** プレッシャー（議員・経済団体への説明責任）
3. 納品後の **運用負荷**（市役所職員に負担を残せない）
4. 既存業者との関係性（地元事業者との取引慣行）

## 7. Shift がこの案件に向き合うスタンス（仮置き）

ここまでの理解を踏まえると、Shiftの提案は次の3つの軸で組み立てるのが妥当。

### 7-1. 「制作会社」ではなく「事業設計パートナー」として手を挙げる
- 冊子・PVは納品物にすぎない。Shiftが提供するのは **「田村の産業の棚卸しと言語化」「マッチングを生む情報設計」「3カ年計画の起点づくり」**
- 制作専業の競合（映像制作・印刷会社・PR代理店）と同じ土俵には乗らない

### 7-2. 田村市での実績を「事情を分かっている強み」に転換
- 田村市ふるさと納税業務委託（R5〜R8継続）、観光デジマ、デジタルスタンプラリー、PR動画、ブランド産品リーフレット、コミプラ空間デザインなど **田村市案件20件以上の累積実績**
- 「田村市の事業者・職員の温度感・意思決定プロセスを既に理解している」が応札時の競争優位
- ※ただし様式3「企業実績調書」は「同種事業（起業者・経営者に対する支援事業等）」が問われており、純粋制作系の実績では弱い可能性 → どう書くか別途検討

### 7-3. 「使われる仕組み」で差別化する
- 既存企画書案にある **特設WEB＋AIコンシェルジュ（RAG）の業務範囲内追加** は、まさに本業務の深層目的に響く打ち手
- ただし「使われる仕組み」をWEBだけに矮小化せず、**冊子の使われ方／PVの拡散導線／市役所の運用負荷低減** までトータルで設計する

## 8. 論点（合意済み）

### 論点1：想定ターゲット ✅
**主軸：A+B（首都圏バイヤー × ソリューション提供企業）／従軸：D（若年層・採用対象者）**
- C（市内事業者同士）は評価④の柱として扱う
- E（ふるさと納税ユーザー）は出口の一つとして間接寄与
- マルチユース設計：冊子=B2B営業ツール／PV本編=B2B／SNS短尺切り出し=若年層／特設WEB=両者対応

### 論点2：選定基準 ✅
**包含型をベースに、候補プール50-80社を大きめに設計→市と協議で確定する2段階プロセス**

- 情報源：A（1,123事業所アンケート）／C（商工会会員リスト）／D（Shift保有のふるさと納税事業者ネットワーク）を主軸、B（SPEEDA等＝市側アドバイザリー業者から提供前提）／E（公開リスト）／F（統計）補強、G（ヒアリング）協議過程で活用
- 特集10P：**案A テーマ特集型**（5テーマ×2P、テーマ例＝小ロット試作／新領域／地域資源／OEMハブ／市内連携）
- マトリクス4P：①加工技術×業種 ②製造工程×対応ロット ③地域マップ ④課題解決領域×対応企業
- 要覧30P：30社×1P 統一フォーマット
- その他20P：巻頭コンセプト4P／エコノミックガーデニング事業6P／WEB・AI活用ガイド6P／巻末4P
- 業種・地域・規模バランス：「8つの選定眼」内で対応、5地区バランス（船引／滝根／大越／都路／常葉）明記

### 論点3：既存事業との接続 ✅
**p15を「3カ年計画ロードマップ」、p16を「主要3事業との接続シナリオ＋役割分担表」に書き換え**
- 主要3事業：中小企業交流セミナー（R8〜）／ビジネスチャンス拡大事業（R9〜）／産業祭（R10）の固有名詞で接続
- 責任範囲：Shift（素材提供＋活用提案＋AIコンシェルジュ運用）／市役所（イベント開催・予算執行）／取材企業（取材協力・登壇）

### 論点4：ふるさと納税寄与 ✅
**独立ページなし、論点3内（p15-16）でしっかり言及**
- 取材プロセスに「返礼品候補商品ヒアリング」を組み込み、返礼品候補リストを自主提案物として納品
- 冊子QRコード／特設WEB → furusato-tamura.jp 動線
- AIコンシェルジュに「ふるさと納税で応援したい」相談導線
- 田村市ブランド認証産品 × 本業務取材企業のクロスオーバー連携
- リスク管理：ふるさと納税業務委託の情報は「Shiftの組織能力として記載」（二次利用ではない）

### 論点5：実施体制 ✅
**Shift（飛田主担当）＋ 外部協力チーム（既存パートナー中心）**

外部協力：スチールカメラマン、映像作家（撮影＋編集）、グラフィックデザイナー、WEB開発エンジニア、ネットプリント、AIコンシェルジュ実装パートナー
取材ライター：手配中（一部飛田兼任の可能性）
進行管理：AI実務ツール活用（※提案書には明記しない）
詳細マップ・役割マトリクス・リスク管理は計画ファイルに記載
