## 1. 事業理解と課題認識

### 事業理解

本業務は、田村市が令和5年度に1,123事業所を対象に実施したアンケート調査の分析結果を起点とし、「エコノミックガーデニング田村本会議」「実務者会合」で得られた**24の提案のうち、「生き残りをかけた中小企業成長戦略事業」の中核施策**として位置づけられる業務である。

私たちが特に重く受け止めているのは、仕様書冒頭に明記された**「将来的に最適なソリューション提供企業とのマッチング事業を展開」**という文言である。これは、**本業務の射程が冊子・PVの納品で終わらず、来年度以降の本格的なマッチング事業本体への前段**であることを意味している。今年度の本業務は、来年度マッチング事業本体が動き出すための**情報基盤・関係性基盤・取材アセット**を構築する任務である。

エコノミックガーデニング田村の3年計画における本業務の位置づけを踏まえ、本年度は**24提案を貫く「共創型産業振興インフラ」の土台を構築する初年度**として、3年計画の自走に直結する設計を行う。

## 2. 提案コンセプト

### 「生き残り」をかけた田村のものづくりに、世界から「逆引き」される基盤を。

「田村の匠」を、列挙型カタログにはしない。

### なぜ"今"、マッチング装置なのか

仕様書には「**将来的に最適なソリューション提供企業とのマッチング事業を展開**」と明記されている。これは、**来年度以降に本格的なマッチング事業本体が動き出す**ことを意味する。本業務は、その**前段としての情報基盤・関係性基盤の構築**である。

来年度マッチング事業本体が動き出した瞬間に「何のデータも、何の関係性も、何の自走機構もない」状態では、本体事業は離陸できない。だからこそ今年度、**事業者の強みが言語化され、共通DBに格納され、市内外から逆引きされ、市内事業者同士が共創コミュニティとして繋がっている状態**を作る必要がある。

私たち受託者の信念は、本業務を**「広報物の制作」ではなく「来年度マッチング事業本体を離陸させる滑走路の建設」として位置づけ直すこと**にある。

### 順引きから逆引きへ ── マッチング装置への転換

これまで多くの自治体・商工団体で制作されてきた企業紹介冊子の多くは、**「企業名 → 事業内容 → 製品写真」という"順引き型"**の構成だった。しかしこの順引きでは、バイヤーは「探したい会社の名前」を先に知っていなければたどり着けない。技術用語がわからなければ比較もできない。冊子を配布し終わった瞬間に情報は静止し、1年後には更新されないまま机の引き出しに眠る。市内事業者同士も、隣の会社が結局何をやっているのかわからないままだ。

本提案は、この順引き型カタログから、**「課題 → 解決できる企業」の逆引き型マッチング装置**への転換を提案する。

### 主役は、田村市の事業者。私たち受託者は黒子に徹する。

事業者が自社の強みに気づく → 言語化される → 市内外から逆引きされる → マッチングが起きる → 受発注・共同開発・販路拡大・採用へつながる → 田村市の産業が"生き残り"を超えて成長する。この循環を生み出すための仕組み・場・道具を設計し、引継ぎ・自走支援まで伴走する。私たちは、事業者と市が"自走できる状態"を3年計画の中で実現するための初年度を担う。

## 3. 基本方針

### 方針1：「カタログ」ではなく「マッチング装置」として設計する

仕様書の目的は「マッチング事業の展開」「販路拡大」である。私たちは、冊子1,000部・PV20社という成果物を、その目的のための**"装置の部品"として再定義する**。冊子は装置の表紙と索引、PVは理解促進、WEBは検索・問合せ機能、AIは24時間窓口、SNSは認知拡大フック。各媒体は独立した制作物ではなく、認知→理解→比較→相談→商談というファネルの一段ずつとして役割分担する。

### 方針2：「解決できる課題」を起点とした逆引き構造で、可視化を徹底する

従来の「企業名 → 事業内容」の順引きではなく、「**課題 → 解決できる企業**」の逆引き構造を全媒体で貫徹する。コンサル型取材で各社の「解決できる課題」を引き出し、冊子マトリクス・WEB検索・AIコンシェルジュで**5軸（技術／課題／業種／地域／連携種別）で同時に逆引きできる構造**を実装する。技術がわからないバイヤーでも、自社の悩みから事業者にたどり着ける状態をつくる。

### 方針3：4媒体ファネル × 市の既存接続施策連動で、マッチングを構造的に加速する

冊子・PV・WEB・SNSの4媒体を、認知→理解→比較→相談→商談の動線で接続する。さらに**トップセールス・異業種交流会・産業祭・ビジネスチャンス拡大事業**等、エコノミックガーデニング田村の既存接続施策と連動させ、装置を単独施策ではなく"束"として動かす。これにより、マッチング接点の絶対量と質を構造的に引き上げる。

### 方針4：自主提案で特設WEB＋AIコンシェルジュを業務範囲内・無償で構築する

仕様書9条「本仕様書以上の最新の技術提供や企画があれば、委託額の範囲内で積極的に採用することを拒まない」を最大限活用し、私たちは**業務範囲内・追加予算なしで、特設WEBデータベースとAIマッチングコンシェルジュ（RAG実装）を構築する**。これにより、冊子・PVで蓄積した「田村の匠」情報を共通資産として残し、納品後も24時間動き続けるマッチング基盤を市に残す。

### 方針5：取材プロセスそのものを、事業者の「気づき」の場にする

取材は記録ではなく、**コンサルティング型対話**とする。「できること」「選ばれている理由」「解決してきた課題」「独自の工夫」「つながりたい相手」「デジタル発信状況」の6視点で深く掘り下げ、事業者自身が自社の強みを再認識する場をつくる。取材した30社が"自分の言葉で自社を語れる状態"になることが、本事業最大の波及効果である。この波及効果は、本質課題P2（個社では解決できない8領域）のうち**経営者育成・事業承継・DX推進**へ直接寄与する。

### 方針6：留意事項②「年齢層・職業・興味関心」に応えるため、4ペルソナ別の接点を設計する

域外バイヤー／市内事業者／求職者・若手／田村市民の4ペルソナごとに、見出し・写真トーン・尺・配信媒体を最適化する。特に**求職者・若手ペルソナ**は、地方中小企業の最大の生き残り課題である**雇用創出**（仕様書8領域の1つ）への直接解として設計する。同じ取材から、冊子要覧（バイヤー向け）／本編PV（理解促進）／SNS縦型短尺（若年層・求職者）と多重展開する。

### 方針7：3年計画の2・3年目を支える「自走できる資産」を残す

本年度の納品物を単年度で終わらせない。WEB＋AIをノーコードCMS＋実費数千円の従量課金で構築し、運用マニュアル＋ハンズオン講習＋並走サポートで、市役所担当者が交代しても運用品質が落ちない設計にする。

### 方針8：24提案の他施策と接続可能な共通インフラとして設計する（NEW）

本業務の納品物（取材30社のソリューション言語化／5軸DB／WEB＋AI／共創コミュニティ）は、本業務単独で完結しない。仕様書本質課題P5「横断的かつ一貫した支援体系」に応えるため、**24提案の他施策（ビジネスチャンス拡大事業／中小企業交流セミナー／産業祭／経営者育成／起業支援／DX推進）すべてに横展開可能な共通インフラ**として設計する。例えば、5軸DBは経営者育成カリキュラムの市場調査素材になり、共創コミュニティは中小企業交流セミナーの登壇候補プールになり、WEB掲示板は起業支援の事業者接続窓口になる。**「田村の匠」基盤を、エコノミックガーデニング田村全体の共通OS**として位置づける。

### 5つの仕掛けが連動して生む、マッチング加速の具体像

仕様書5(2)留意事項①の「マッチング機会やマッチングによる新商品開発、販路拡大の創出」を実現するためには、単に企業を紹介するだけでは不十分である。マッチングが構造的に生まれる「仕掛け」を設計しなければならない。

例えば、域外バイヤーが「軽くて頑丈なアウトドア用の五徳を試作したい」と問合せたとする。
- 従来の冊子では、「金属加工」のカテゴリから順に企業を探さなければならない。営業時間外なら問合せもできない。
- 本提案の装置では、TAKUMI-AIが即座に「精密板金・小ロット対応・試作実績あり」の3条件で〇〇製作所をマッチング、個別PVを再生して技術力を確認、QRから問合せフォームへ。**バイヤーは10分以内に商談アポイントメントに到達できる**。

これが「可視化×マッチング加速」が生む具体像である。可視化（①②）が認知度・比較容易性を上げ、加速（③④⑤）が接点機会の絶対量と質を上げる。結果として「マッチング件数」「相談件数」「成約件数」が定量的に伸びる。

## 14. マッチング加速 ── 地域内 × 域外 × 既存接続施策連動

### 「装置」を動かす3つの加速メカニズム

装置を構築するだけでは、マッチングは生まれない。私たちは、装置を「動かす」3つの加速メカニズムを実装する。

### ① 地域内マッチング ── 市内企業同士が「互いの強みを知り、組める」状態へ

| 連携機会 | 内容 |
|---------|------|
| 市内受発注 | これまで市外に出ていた仕事を、市内企業同士で受発注 |
| 共同開発 | 複数社で技術・商品・素材を組み合わせ、新商品を生む |
| 技術補完 | 自社単体では対応できない工程・ロットを、市内企業間でカバー |
| 販路共有 | EC・展示会枠を共有し、共に販路拡大 |

**【加速の核】WEB掲示板機能**：「今、この技術を探しています」「余った端材を譲ります」「共同で展示会出展しませんか」という一言を、市内事業者が常時発信できるプラットフォームを設ける。**待ちの問合せから、攻めの発信へ。**

### ② 域外マッチング ── 「田村市に相談すれば、解決策が見つかる」

課題起点の接続例：

| バイヤーの困りごと | TAKUMI-AIの推薦例 |
|----------------|-----------------|
| 小ロットで試作品を作りたい | 試作対応・柔軟な金属/樹脂加工事業者 |
| 地域資源を活用した商品を開発したい | 食品・木材・農産物・伝統工芸事業者 |
| OEM先を探している | 製造・加工・パッケージ一括対応事業者 |
| 地方企業と共同開発したい | 市内企業＋商工団体＋行政支援制度のセット提示 |

WEBサイト上のPVを首都圏の企業が確認するだけで、現地に行かずとも一次スクリーニング（技術レベルの確認）が完了する仕組みを提供する。

なお、**取材30社のうち消費者向け商品を持つ事業者については、ふるさと納税返礼品化を販路拡大の選択肢として市と協議のうえ提示する**（仕様書5(2)留意事項③への対応）。本業務は事業者の販路選択肢を整理する役割を担い、返礼品化の運用は市の返礼品事業者選定プロセスに委ねる。

### ③ 市の既存接続施策との連動 ── 単独施策ではなく束で動かす

仕様書5(2)①に明記された既存事業（ビジネスチャンス拡大事業、中小企業交流セミナー、産業祭等）と装置を構造的に連動させる。

| 接続施策 | 連動の仕方 |
|---------|----------|
| **トップセールス** | 冊子＋ダイジェスト動画＋名刺裏QRをセットで持参。市長・職員が説明しやすい構成に |
| **異業種交流会・産業祭** | マトリクス表ポスター掲示＋TAKUMI-AIデモブース＋WEB掲示板のリアルタイム表示 |
| **ビジネスチャンス拡大事業** | WEB掲示板を一次マッチング窓口とし、商工課職員のフォローへ接続 |
| **中小企業交流セミナー** | 取材30社のなかから登壇候補を抽出、事例共有の素材を提供 |
